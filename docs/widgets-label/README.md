# widgets-label — initiative README

This initiative ratifies `lvglpp::widgets::Label` — the smallest
concrete widget, used as the smoke-test for the end-to-end widget
surface (Event → Widget → Renderer → Style → Font).

This README is **informative**. The normative artifact is the chapter
[`00-label.md`](./00-label.md).

## Status

Chapter ratified at draft level (2026-04-27). WID-01 execution is
unblocked by ratification of CORE-02 / CORE-03 / CORE-04 / CORE-05
and minimal landing of CORE-04a draw helpers.

## Cross-language pair

Mirrors `rlvgl/widgets/src/label.rs` (v0.2.0 @ b178cbc). No rlvgl
change is required to land lvglpp's WID-01 implementation.
