# core-layout — initiative README

Wraps LVGL's flex and grid layout engines plus sizing as C++ over
`lv_obj_set_flex_*` / `lv_obj_set_grid_*`. Supersedes the stubbed UI-04
layout helpers.

This README is **informative**. The normative artifact is
[00-layout.md](./00-layout.md) (**LPAR-10**); the umbrella is
[`../lpar/README.md`](../lpar/README.md). Mirrors rlvgl `v0.2.4`
`docs/concepts/LPAR-10-LAYOUT.md`.
