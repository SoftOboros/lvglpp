# core-scroll — initiative README

Wraps LVGL's scroll runtime (flags, scrollbars, snapping, throw/momentum)
as RAII C++ over `lv_obj_scroll_*`, on the WRAP-00 `Object`.

This README is **informative**. The normative artifact is
[00-scroll-runtime.md](./00-scroll-runtime.md) (**LPAR-05**); the umbrella
is [`../lpar/README.md`](../lpar/README.md). Mirrors rlvgl `v0.2.4`
`docs/concepts/LPAR-05-SCROLL-RUNTIME.md`.
