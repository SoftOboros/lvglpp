# lvglpp::ui

Library: `lvglpp::ui` (CMake target: `lvglpp_ui`, alias `lvglpp::ui`).

`lvglpp::ui` provides higher-level UI compositions on top of
`lvglpp::widgets` — theming, layout helpers, draw helpers,
event-window utilities. Triangulated from
[`rlvgl-ui`](../rlvgl/ui/) over upstream
[LVGL](../lvgl/src/) themes / layouts / draw.

## Status

INTERFACE target only — no implementation yet. See
[`STATUS.md`](./STATUS.md) for the landing plan.
